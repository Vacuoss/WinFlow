# WinFlow

WinFlow is a lightweight software KVM for Windows.

It allows you to use two Windows devices like one workspace over your local network.

You can:
- move your cursor between devices
- share clipboard instantly
- control another PC without remote desktop

---

# How it works

WinFlow connects two devices directly through your local network.

When the cursor reaches the selected screen edge, control switches to the second device like it was another monitor.

No cloud servers are used.

# Features

- Seamless cursor transition
- Clipboard sync
- Low latency input
- Custom hotkeys
- Auto update
- Local network only

---

# Requirements

- Windows 10 or Windows 11
- Both devices connected to the same local network

---

# Installation

1. Download the latest installer from Releases
2. Run `WinFlowSetup.exe`
3. Install WinFlow on both devices

Optional:
- Create desktop shortcut
- Start with Windows

---

# How to connect devices

1. Open WinFlow on both devices
2. Enter the IP address of the second device
3. Press `Connect`

You can now move the cursor between devices.

---

# Switch edge

Switch edge controls where the cursor moves to the second device

right — cursor switches to the second device when reaching the right edge

left — cursor switches to the second device when reaching the left edge

top — cursor switches to the second device when reaching the top edge

bottom — cursor switches to the second device when reaching the bottom edge

---

# Hotkeys

Default hotkeys:

- Switch control:
`Ctrl + Alt + Right`

- Disconnect:
`Shift + LeftAlt`

Hotkeys can be changed in Settings.

---

# Security

WinFlow works only inside your local network.

Devices communicate directly with each other.

No data is sent to external servers.
