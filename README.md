# WinFlow


WinFlow lets you use two devices like one setup
 
---

# Features:
<img width="491" height="629" alt="image" src="https://github.com/user-attachments/assets/c3c9404d-8a0f-4671-b73c-5f6af304f5e9" />

## Cursor transition

Move the mouse between devices naturally, similar to a second monitor.

Supports:
- Windows 10
- Windows 11
- fullscreen apps
- different resolutions
- low latency input

## Clipboard sync

Copy text on one device and paste on the other instantly.

## Hotkeys

Customizable hotkeys for:
- switching control
- disconnecting devices

---

# Local network only

WinFlow works only inside your local network.

No cloud servers are used.

Devices communicate directly with each other.
